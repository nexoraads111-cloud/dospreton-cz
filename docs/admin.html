Administrace galerie

Nahrávejte fotografie realizací z telefonu nebo počítače. Soubory JPEG / PNG / WebP, max 5 MB. Veřejný web je načte ze Supabase po obnovení stránky.

Chybí konfigurace Supabase. Zkopírujte js/supabase-config.example.js → js/supabase-config.js a doplňte Project URL + publishable key. Postup: VANILLA-GALLERY.md.

Přihlášení

Účet vytvořte v Supabase → Authentication → Users (bez veřejné registrace).

Nahrát fotografie

Úložiště: bucket gallery, cesta {userId}/{uuid}.ext.
