# DOSPRETON s.r.o. — marketingový web

Jednostránkový marketingový web stavební firmy **DOSPRETON s.r.o.** (Vite + React).

## Lokální spuštění

```bash
npm install
npm run dev
```

Otevřete URL z terminálu (obvykle `http://localhost:5173`).

## Produkční build

```bash
npm run build
npm run preview
```

## Obsah

- Header / navigace + CTA
- Hero
- Služby
- O nás
- Realizace (carousel)
- Kontakt / patička (IČO, DIČ, sídlo Praha–Bohnice)
